
# Cynbit Website Redesign

A responsive website redesign concept created as part of a UI/UX Design Intern assessment.

## Project Overview

This project aims to improve the website experience through a modern interface, clear navigation, responsive layouts, and user-friendly interactions.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive navigation
- Modern dark-tech design
- Services and contact pages
- Interactive UI elements
- Client-side contact form validation
- Responsive layouts for desktop and mobile

## Project Structure

- `index.html` — Homepage
- `services.html` — Services page
- `contact.html` — Contact page
- `css/style.css` — Website styling
- `js/script.js` — Interactive functionality

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## Deployment

The website will be deployed using Vercel.

## Note

This is a redesign concept created for learning and assessment purposes. It is not the official Cynbit website.
